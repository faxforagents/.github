# Fax for Agents

Fax for Agents is a fax API, a hosted MCP server and SDKs built so AI agents can send and receive faxes. It is made by JSB Holdings LLC and built by [Synapse](https://synapsereality.io/).

- [faxforagents.com](https://faxforagents.com): the product, the pricing and the docs
- [openapi](https://github.com/faxforagents/openapi): the OpenAPI document and the rendered reference
- [sdk-python](https://github.com/faxforagents/sdk-python): the Python client and the `faxforagents` command
- [sdk-typescript](https://github.com/faxforagents/sdk-typescript): the TypeScript and JavaScript client
- [mcp](https://github.com/faxforagents/mcp): the MCP server, hosted at mcp.faxforagents.com or on your machine over stdio
- [examples](https://github.com/faxforagents/examples): runnable examples against the sandbox

Questions and problems: hello@faxforagents.com.
